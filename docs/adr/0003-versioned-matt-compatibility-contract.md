# Bind each Matrix release to one reviewed Matt Skills release

Matrix 0.1.4 supports Matt Skills v1.2.3 rather than following mutable `main` or the newest upstream release at execution time. It reviews all 25 official roles and installs only the 23 compatible Skills; `implement` and raw `resolving-merge-conflicts` are excluded because their lifecycle side effects conflict with Matrix ownership. A project's Matrix Runtime and Matt receipt are its compatibility authority: they outrank global installations and cannot be completed by mixing in global Matt Skills. A 0.1.4 global launcher auto-delegates only to an exact, hash-verified 0.1.4 project Runtime; different or unidentified project releases require explicit direct invocation, and older launchers cannot be made to provide that newer guarantee. Matrix installation scope controls Skill discovery only; Matt is always installed and recorded in the target project. `matrix init --with-mattpocock` is the only Matt write path, while `matrix update` updates Matrix and reports Matt compatibility read-only. Future Matt releases require a reviewed Matrix patch that changes the compatibility contract, preserving reproducibility and preventing upstream changes from silently altering existing Matrix versions or active Arch changes.
